Software Download Page

Welcome to our curated collection of software packages, distributed as .tar.gz archives. Simply download and extract to /, the -h flag is important, so that system symbolic links are kept intact.

sudo tar xvf ~/Downloads/PACKAGE.tar.gz -hom -C /
